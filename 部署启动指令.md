# 部署启动指令

## UI 启动（工作机；推理与执行分别启停，执行自动 up）

```bash
cd "$HOME/LTT/franka3-sharpa-pi05-chunk-base-test"
bash deploy/fr3_sharpa_control/ui.sh
# 浏览器打开 http://127.0.0.1:8766
# 选择权重/模式 → 启动推理 → 等预热就绪
# 选择Current/Home、步数、录制 → 核对执行配置 → 启动执行（自动up）
# 停止执行：保留推理；再次执行仍自动up
# 停止推理：先等执行及失能清理结束，再点击停止推理
# 日志区固定：终端一硬件／终端二推理／终端三执行
```

## Paper T3 Delta／7999：使用下方Delta对应场景；仅替换公共配置的权重路径

```bash
# 在 paths.env 中将 SHARPA_DELTA_CHECKPOINT 指向工作机上完整的7999目录。
# 目录内必须同时保留 params/ 和 assets/；不要只复制 norm_stats.json。
# UI中直接选择7999并点击“识别权重”，自动显示 timestamp_zscore_arms / beta0.5。
# main可选普通串行/RTC；Soft分支可再选串行Soft/异步Soft。
# 三终端沿用下方 --model full-delta；无需增加Paper开关或使用新脚本。
```

## 三终端共用路径：每台工作机只配置一次；替换仓库/权重目录为本机实际位置

```bash
mkdir -p "$HOME/.config/sharpa-deploy"
cat > "$HOME/.config/sharpa-deploy/paths.env" <<'EOF'
export SHARPA_MAIN_REPO="$HOME/LTT/franka3-sharpa-pi05-chunk-base-test"
export SHARPA_SOFT_REPO="$HOME/LTT/franka3-sharpa-pi05-soft-inpainting-test"
SHARPA_DESKTOP="$(xdg-user-dir DESKTOP 2>/dev/null || true)"
if [[ -z "$SHARPA_DESKTOP" || ! -d "$SHARPA_DESKTOP" ]]; then
  if [[ -d "$HOME/桌面" ]]; then SHARPA_DESKTOP="$HOME/桌面"; else SHARPA_DESKTOP="$HOME/Desktop"; fi
fi
export SHARPA_ABSOLUTE_CHECKPOINT="$SHARPA_DESKTOP/sharpa_tomato_ckpt_4000"
export SHARPA_DELTA_CHECKPOINT="$SHARPA_DESKTOP/sharpa_1016_2_fullft_delta_30hz/5999"
export SHARPA_RECORDINGS_DIR="$SHARPA_DESKTOP/Sharpa部署记录"
source "$SHARPA_MAIN_REPO/deploy/fr3_sharpa_runtime/env.sh"
export SHARPA_PYTHON="${SHARPA_PYTHON:-$SHARPA_MAIN_REPO/.venv/bin/python}"
export SHARPA_HOME_POSES="${SHARPA_HOME_POSES:-$SHARPA_MAIN_REPO/.deployment/operator_poses.yaml}"
export SHARPA_HAND_HOME="${SHARPA_HAND_HOME:-$SHARPA_MAIN_REPO/.deployment/hand_home.json}"
if [[ -d "$SHARPA_MAIN_REPO/.deployment/sharpa_ros_messages/install" ]]; then
  export SHARPA_ROS_MESSAGES_OVERLAY="${SHARPA_ROS_MESSAGES_OVERLAY:-$SHARPA_MAIN_REPO/.deployment/sharpa_ros_messages/install}"
fi
EOF
```

## main · ABSOLUTE · 普通串行：每轮执行前15个模型动作，可改20

### 终端一：硬件

```bash
source "$HOME/.config/sharpa-deploy/paths.env"
cd "$SHARPA_MAIN_REPO"
bash deploy/fr3_sharpa_runtime/hardware.sh up
```

### 终端二：模型服务（等待预热成功及监听信息）

```bash
source "$HOME/.config/sharpa-deploy/paths.env"
cd "$SHARPA_MAIN_REPO"
export SHARPA_CHECKPOINT="$SHARPA_ABSOLUTE_CHECKPOINT"
bash deploy/fr3_sharpa_runtime/serve.sh --model full
```

### 终端三：Current 持续执行；自动录制（开关1/0），自动日期与编号

```bash
source "$HOME/.config/sharpa-deploy/paths.env"
cd "$SHARPA_MAIN_REPO"
export SHARPA_CHECKPOINT="$SHARPA_ABSOLUTE_CHECKPOINT"
export SHARPA_RECORD_ENABLED=1
bash deploy/fr3_sharpa_control/record_execute.sh -- \
  bash deploy/fr3_sharpa_runtime/runtime.sh --model full --broker-mode serial \
  --execute --enable-hardware --sharpa-backend sdk_direct \
  --initialization current --hand-home "$SHARPA_HAND_HOME" --speed slow --execute-steps 15 --num-chunks 0
```

## 先回固定双臂、双手 Home 再开始：替换执行命令的这一项

```bash
--initialization home
```

## 有限轮数：替换执行命令的这一项（RTC 至少2轮，异步Soft示例3段）

```bash
--num-chunks 3
```

## 停止：执行终端按一次 Ctrl-C，等待失能读回确认、硬件清理和录制关闭

```text
Ctrl-C
```

## 切换权重或模式：终端三停止并等失能/清理完成后，在终端二停止旧模型，再按新场景启动

```text
终端二：Ctrl-C
```

## 再次执行：保留匹配的模型服务，先在终端一重新 up，再运行对应终端三

```bash
bash deploy/fr3_sharpa_runtime/hardware.sh up
```

## 遗留部署容器清理

```bash
bash deploy/fr3_sharpa_runtime/hardware.sh stop
```

## 单独重新导出某次已关闭的 bag（已有视频不覆盖，失败产物需先移走）

```bash
bash deploy/fr3_sharpa_control/record_session.sh export \
  "/本机实际归档父目录/YYYY-MM-DD/01"
```
